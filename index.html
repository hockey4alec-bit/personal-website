Project 001 / Optimization

Delivery Route Optimizer

A Python application that plans a delivery route starting and ending at a depot. It reads locations from CSV, retrieves road distances from OSRM, builds a nearest-neighbor route, and improves it using 2-opt local search.

Compares route distances and displays the resulting route on an interactive, road-following map with numbered delivery stops.

Status: Working prototype published on GitHub, with seven automated tests passing.

Tools: Python, OSRM, Requests, Folium, OpenStreetMap, Git/GitHub.
